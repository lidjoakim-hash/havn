Job Overview Assignment Description We are looking for a .NET Cloud Developer to contribute to API development, application maintenance and continuous improvement activities. What You Will Work On Develop and enhance APIs using .NET and cloud technologies. Support users by explaining system capabilities, answering questions and resolving incidents. Analyse user issues and help business users use APIs effectively. Identify actual and potential software problems. Participate in application maintenance and enhancement planning. Identify opportunities to automate repetitive tasks. Promote development best practices and continuous improvement. Write, review and refactor clean, scalable and testable code. What You Bring Experience working in the BDIP Penta Team. At least 5 years of total IT experience. At least 3 years of .NET cloud development experience. Hands-on experience with code repositories and CI/CD tools such as GitHub Actions, Azure DevOps Pipelines or GitLab. Experience using Azure DevOps for development and deployment. Proven experience implementing solutions on Microsoft Azure. Understanding of containerization technologies such as Kubernetes. Exposure to cloud platforms such as Microsoft Azure or AWS. Knowledge of SQL Server and/or Azure SQL Database. Strong understanding of the complete web development lifecycle, including design, development and deployment. Proficiency in microservices architecture. Experience with unit testing, integration testing and/or Test-Driven Development (TDD). Strong understanding and application of SOLID principles. Ability to translate business requirements into technical solutions. Ability to review and refactor code effectively. Meritorious Experience improving application performance and optimizing solutions. Experience automating repetitive development and operational tasks.
