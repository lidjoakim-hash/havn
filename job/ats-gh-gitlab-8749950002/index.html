An overview of this role As a Backend Engineer on the Plan: Spec-Driven Development team, you'll help build GitLab's intent-to-code loop: agentic workflows that turn a stated intent into a refined work item, an implementation plan, and verified, mergeable code. You'll own early-stage backend work across the flows, application programming interfaces, data models, and evaluation systems behind this experience, using Ruby on Rails, Python, PostgreSQL, GitLab Duo Agent Platform, large language model application programming interfaces, and an artificial intelligence gateway. You'll join a small, distributed team working on one of GitLab's highest-visibility product bets, collaborating with design partners toward a public beta.
