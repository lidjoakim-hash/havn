DevSecOps Engineer

Knowit Aktiebolag (publ) · Göteborg, Sweden

💰 ca. 490 000–640 000 SEK/år (estimat · vanlig lønn, ikke bekreftet)Heltidvia ArbetsförmedlingenFrist 31.1.2027

Søk på stillingenÅpne i Havn (lagre, sammenlign, KI-hjelp)

Vill du bygga säkra molnplattformar där automation och säkerhet följer hela leveransen? Som DevSecOps Engineer kombinerar du arkitektur med praktisk utveckling i varierande kunduppdrag. Du designar, automatiserar och vidareutvecklar molnmiljöer och utvecklingsflöden för kunder inom olika branscher. Säkerhet är en naturlig del av hela livscykeln, från kod och infrastruktur till deployment och drift. Uppdragen kan finnas inom bland annat försvar, autonoma fordon, infotainment och 5G. Du arbetar agilt tillsammans med utvecklare samt drift- och säkerhetsteam, både internt och ute hos kund. Rollen omfattar bland annat att: bygga säkra CI/CD-pipelines och integrera automatiserade kontroller för SAST, SCA samt container- och sårbarhetsskanning konfigurera, säkra och optimera molnplattformar i Azure, AWS eller GCP automatisera infrastruktur och processer med Terraform, Ansible, Bash eller Python arbeta med Infrastructure as Code och Policy as Code för att skapa repeterbara, spårbara och säkra miljöer hantera Docker, Kubernetes och plattformar som AKS, EKS eller GKE, inklusive IAM, secrets management och principen om least privilege använda monitorering, loggning och observability för att identifiera avvikelser, sårbarheter och incidenter Du får kombinera strategiskt arbete kring arkitektur, säkerhet och arbetssätt med praktisk implementation och automation. Genom security by design och shift left bidrar du till att säkerhet byggs in tidigt i utvecklingsprocessen. För att lyckas i rollen ser vi att du har: minst tre års erfarenhet av Cloud Engineering, DevOps, DevSecOps eller liknande gedigen erfarenhet av Azure, AWS eller GCP samt god förståelse för cloud security, exempelvis IAM, nätverkssäkerhet, secrets management och least privilege erfarenhet av CI/CD och automatiserade kvalitets- och säkerhetskontroller i pipelines erfarenhet av Terraform och/eller Ansible samt ett security by design-perspektiv på Infrastructure as Code goda kunskaper i Bash och/eller Python samt erfarenhet av versionshantering, artifact- och repository management, monitorering och loggning erfarenhet av Docker och Kubernetes samt förståelse för image scanning, RBAC, secrets och nätverkspolicies Meriterande Det är meriterande om du har arbetat med DAST, Policy as Code eller verktyg som OPA, Gatekeeper och Kyverno. Erfarenhet av HashiCorp Vault eller motsvarande tjänster hos molnleverantörer är också relevant. Vi ser positivt på kunskap om CIS Benchmarks, NIST, ISO 27001, threat modeling, riskanalyser eller säkerhetsgranskningar. Detsamma gäller erfarenhet av mjukvaruutveckling i exempelvis Java, .NET, Rust, Go, C++ eller Swift samt relevanta certifieringar inom cloud, Kubernetes eller cybersäkerhet. Vad får du hos oss? Som konsult får du arbeta med varierande uppdrag och ha inflytande över teknikval, arkitektur och arbetssätt. Du blir en del av en miljö där initiativ, lagarbete och kunskapsdelning är centrala delar av vardagen. I vårt Greenhouse kan du experimentera med teknik, utveckla idéer, bygga prototyper och dela kunskap med kollegor. Här finns utrymme att fördjupa din kompetens inom moln och DevSecOps samtidigt som du bidrar till moderna, robusta och säkra lösningar. Ansökan Vi arbetar med löpande urval, så skicka gärna in din ansökan så snart som möjligt. Om Knowit Jobba hos oss på Knowit Connectivity, där vi arbetar med tekniskt avancerade system inom embedded och uppkopplade lösningar. Hos oss får du arbeta med komplexa produkter tillsammans med erfarna ingenjörer i uppdrag som ligger i teknisk framkant. Knowit är ett nordiskt konsultbolag som hjälper företag, myndigheter och organisationer att lyckas i den digitala transformationen. Med expertis inom systemutveckling, AI, cybersäkerhet, molntjänster, digitala kundupplevelser och managementkonsulting utvecklar vi lösningar som bidrar till ett mer hållbart och mänskligt samhälle. Vi är cirka 3 700 medarbetare och arbetar genom våra affärsområden Solutions, Experience, Connectivit
