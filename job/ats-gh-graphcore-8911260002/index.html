About the job Build the test strategy that protects Graphcore’s system software releases at scale. As a Staff System Software Engineer, you will shape integration and system testing across firmware, BMC and Linux device drivers. Your work will help create a high quality gate for system software release packages. You will design, build, automate and report tests across complex server class systems. You will also develop reusable tools, pipelines and packaging solutions that help teams move faster with confidence. This role needs deep low level software knowledge and strong system thinking. You will own hard technical areas, guide best practice and stay close to the code. The team and culture You will join a new integration and system test team within System Software QA. The team verifies integrated components across BMC, firmware and Linux device drivers. Work happens close to the hardware, across component teams and QA. You will partner with developers, consult package stakeholders and turn use cases into robust system tests. Decisions are shaped by evidence, clear technical reasoning and ownership. You will be expected to speak up, act fast and raise standards through hands-on leadership. What we’re looking for · Strong experience in low level system testing and integration across complex software and hardware layers. · Deep understanding of RTOS, complex boot logic, Linux and device drivers. · Test development capability using Python and C/C++. · Experience working with hardware, debuggers, CI/CD pipelines and build or integration tools. · Ability to debug cross-layer issues and drive root-cause investigations to lasting corrective actions. · Clear communication skills, with the ability to mentor engineers and document complex technical decisions. While we have outlined a set of requirements, we value transferable skills and diverse experiences. If you meet most of our essential criteria, we encourage you to submit an application and showcase how your background makes you a strong candidate.
