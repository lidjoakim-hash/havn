Veritaz is a leading IT staffing solutions provider in Sweden, committed to advancing individual careers and aiding employers in ensuring the perfect talent fit. With a proven track record of successful partnerships with top companies, we have rapidly grown our presence in the USA, Europe, and Sweden as a dependable and trusted resource within the IT industry. Job Overview Assignment Description We are looking for a Professional Front-End Developer to join a product engineering team developing customer-facing features for a digital services portal. You will take end-to-end ownership of front-end solutions, from requirements clarification and UX collaboration through development, testing, release, production monitoring and continuous improvement. What You Will Work On Design and develop responsive, accessible web applications using React and TypeScript. Own front-end features from requirements and UX design through production release. Build reusable, secure, maintainable and well-tested UI components. Integrate applications with REST and GraphQL APIs. Contribute to front-end architecture, state management and technical decisions. Develop unit, component, integration and end-to-end tests. Improve performance, accessibility, browser compatibility and reliability. Deploy, monitor, troubleshoot and continuously improve production applications. Collaborate with Product Owners, UX Designers, Back-end Developers and engineers. Conduct code reviews, share knowledge and support less-experienced developers. Use AI-assisted development tools responsibly and validate generated code. What You Bring Minimum 5 years of relevant front-end development experience. Strong skills in JavaScript, TypeScript, React, HTML and CSS. Experience with modern front-end architecture, reusable components and state management. Experience integrating REST or GraphQL APIs. Practical experience with Git, CI/CD, package management and build tools. Experience with Jest, React Testing Library or Cypress. Strong understanding of accessibility, responsive design, browser compatibility and front-end security. Ability to work with Figma designs and collaborate with UX designers. Experience working in Agile teams using Scrum or Kanban. Strong ownership, analytical problem-solving and communication skills. Fluent English, spoken and written. Meritorious Experience with design systems and component libraries. Knowledge of Node.js, Server-Side Rendering (SSR) or Micro Frontend architecture. Experience with WebSockets, event-driven interfaces or real-time applications. Experience with AWS, observability tools or cloud-hosted applications. Knowledge of clean architecture and front-end performance optimisation. Experience with AI-assisted tools such as GitHub Copilot, Amazon Q, Kiro, MCP Servers or AI Agents. Degree in Software Engineering, Computer Science, Interaction Design or equivalent practical experience.
