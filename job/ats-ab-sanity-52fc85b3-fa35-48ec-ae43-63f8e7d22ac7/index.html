We're hiring a senior engineer for Agent Foundations, the team responsible for how agents work with structured content at Sanity. We own two products. Content Agent https://www.sanity.io/content-agent runs content operations (bulk edits, audits, translation, publishing) through conversation in Sanity Dashboard, Slack, Linear and a headless API. Sanity Context https://www.sanity.io/context (including Knowledge Bases https://www.sanity.io/docs/ai/sanity-context-knowledge-bases) is an MCP endpoint that gives any agent structured retrieval and semantic search over a team's live content, whether it be Sanity Documents or your own federated content from outside Sanity. We're looking for someone who's built AI systems people can depend on in production. At Sanity.io http://Sanity.io, we build an AI-powered content operating system that lets teams model, create, and automate content the way their business actually runs. SKIMS, Figma, Riot Games, Anthropic, COMPLEX, Nordstrom, and Morningbrew run their content operations on it. Most AI products add a model to a content store. We work on what sits underneath. We build knowledge bases from Sanity datasets https://www.sanity.io/content-lake and external sources, and retrieval that combines GROQ filters with keyword and embedding search. Our agents need to understand schemas, references and validation rules. Telemetry and evals tell us how well the systems work. You'll work across these systems, owning your domain end to end and working closely with product and design to decide what gets built next. WHAT YOU'D BE DOING: - Build retrieval and knowledge bases. Turn sources into documents and chunks. Develop how knowledge bases are created, kept fresh and scoped, and how agents query them using GROQ, keyword and semantic search together. - MCP endpoints and tools give agents their interface to our systems. You'll build these, along with tools and integrations that extend Content Agent. - Work on agent loops. Write the orchestration logic that controls an agent's actions and their order, including when to bring a human in. - Engineer system prompts. Give agent instructions the same engineering attention as the code around them. - Measure and improve reliability, retrieval quality and cost through evals, telemetry and experiments. We measure it in production as well as on test sets. - Ship across the stack. Build interfaces in Dashboard and Studio, APIs and backend services. Work on Blueprints, the infrastructure-as-code path customers use to define their agents and knowledge. - Help shape the products. Sanity Context is new and changing quickly. You'll have considerable latitude to decide what it and Content Agent become.
