Ønsker du nye utfordringar i IT bransjen? Nordfjordnett er på jakt etter ein rådgjevar som vil styrke arbeidet med å levere dei sikraste, smartaste og mest stabile løysingane til kommunane våre i Nordfjord.  På avdelinga vår Server og applikasjon, driftar vi serverar, fagsystem, integrasjonar, IT utstyr og tek i vare sikkerheita i løysingane for kommunane Bremanger, Gloppen, Kinn, Stad og Stryn. Stillinga vil i hovudsak innebære administrative oppgåver som prosjektkoordinering, organisatorisk arbeid med informasjonssikkerheit, lisensadministrasjon, avtaleforvaltning og systemdokumentasjon. For å lukkast i denne rollen er det viktig at du trivst med å jobbe med administrative oppgåver knytt til IT.  Server og applikasjon er ei av tre avdelingar på driftssenteret som er plassert i Deknepollen. Samarbeidet omfattar også ei strategisk eining for digitalisering og utvikling som er lokalisert på Nordfjordeid.  Nordfjordnett har hovudkontor i Deknepollen ved Måløy.
