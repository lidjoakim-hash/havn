As a Software Engineer Intern, you will work on meaningful projects that directly impact our product, collaborating with experienced engineers and contributing to challenges at scale. During your internship, you will have the opportunity to work on one of the following projects: Project overview in the Data Ingestion team: The Data Ingestion team is in charge of how customer data gets into Pigment, notably through our library of connectors to external systems. Upgrade, migrate and improve our connector library Upgrade and migrate existing connectors to newer versions and approaches. Improve the reliability, performance, and consistency of the connector library. Contribute to shared tooling and documentation to make new connectors faster to build. Project overview in the Modeler team: The Modeler team builds the AI-powered tools that help customers create and evolve planning models in Pigment. Importing a model from another planning tool with the Modeler Agent  Explore whether recent progress in LLMs and the Modeler Agent makes it possible to recreate a model from another planning tool in Pigment. Design an automated approach to translate its structure, dimensions, and formulas into Pigment blocks and valid formulas. Define tests to validate that the imported model behaves as expected.
