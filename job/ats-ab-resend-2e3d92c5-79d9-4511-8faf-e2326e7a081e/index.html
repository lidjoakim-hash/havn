Resend is growing fast, and there are now over 4 million developers using it. We’re building tools that make email better for developers. We care about dependable infrastructure, thoughtful design, and the experience of everyone building with our products. On our DevTools Squad, you’ll work across our SDKs, React Email, CLI, MCP, and integrations, alongside the backend services that support them. Your work will help developers build within their existing workflows, understand failures, and confidently depend on Resend as their applications grow. This role is fully remote based in Americas or European timezones, with some expected travel for team offsites, conferences, meetups, and more. Read more about how we work, how we hire, and what we value here https://resend.com/handbook. IN THIS ROLE, YOU WILL… - Build and maintain developer tools that make Resend easy to integrate with across languages, frameworks, and environments - Build and operate services that support our developer tools and integrations - Collaborate with product squads on clear API contracts and consistent behavior across SDKs, CLI, MCP, and documentation - Build the interfaces developers and agents use to work with Resend, such as MCP, skills, and the CLI - Take care of compatibility, testing, releases, and upgrades so developers can depend on what we ship - Build shared tooling that helps other squads ship changes across our developer tools confidently - Work directly with developers through support, GitHub issues, and pull requests YOU WILL BE A GREAT FIT IF YOU... - Have strong backend engineering experience, including building and maintaining APIs or services in production. - Care about interface design, clear errors, useful documentation, and backward compatibility - Think about agents as users of a product, with their own needs for discovery and security - Can take an ambiguous problem, propose a focused solution, and follow through after release - Communicate clearly, welcome feedback, and take ownership while working closely with others YOU WILL BE AN EXCEPTIONAL FIT IF YOU ALSO... - Have maintained an open source project or worked closely with external contributors -
