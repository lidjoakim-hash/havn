Key Responsibilities • Work closely with development and product teams to ensure product quality in a fast-paced Agile environment. • Create and maintain test strategies, test plans, test cases, test data and traceability for new features and defect fixes. • Write and maintain automated tests for web applications, REST APIs and data-validation workflows. • Integrate and maintain automated test suites within CI/CD pipelines to support continuous testing, quality gates and release validation throughout the software delivery lifecycle. • Execute manual functional, regression, integration and exploratory testing where automation is not yet appropriate. • Validate multi-tiered, data-driven applications processing large volumes of records. • Define and track quality metrics including defect counts, severity, test execution, coverage and release status. • Identify, document, report, track and verify issues through resolution. • Perform root-cause analysis and collaborate on preventive quality improvements. • Support product deployments, release validation and QA sign-off. • Partner with support teams to reproduce and troubleshoot customer-reported issues. • Proactively improve quality through collaboration, automation, process improvement and innovative thinking. Key Requirements • Bachelor's degree in Computer Science, Information Systems or a related field, or equivalent relevant experience. • Typically 5-8 years of relevant experience, including 5+ years in software quality assurance or quality engineering. • Experience in manual testing across web, API, database and enterprise applications. • Experience in test automation using Playwright, Selenium, Robot Framework or similar tools. • Experience integrating automated test frameworks into CI/CD pipelines using GitHub Actions, Jenkins, Azure DevOps, GitLab CI/CD or similar platforms. • Understanding of continuous integration, continuous delivery, quality gates, automated test reporting and release validation processes. • Proficiency in Java, Python or C# for test automation and scripting. • Strong knowledge of API testing using Postman, REST Assured or equivalent tools. • Experience in SQL and database validation, including complex queries and joins. • Experience designing and executing functional, integration, system, regression and UAT testing. • Experience working in Agile/Scrum environments. • Strong defect management, root-cause analysis and troubleshooting skills. • Experience with JIRA, Zephyr, Azure DevOps or similar test management tools. • AI tools adoption: Demonstrated experience using Copilot, Cursor, Gemini, ChatGPT or Claude for test case generation, test automation, defect analysis, requirements review, CI/CD pipeline optimisation and QA productivity improvements. • Excellent analytical, written and verbal communication, cross-functional collaboration and stakeholder management skills.
