🚀 We’re Hiring: Embedded Software Integration Engineer – Automotive Platform & Verification Company: Hykmann Global Business Solutions AB Role: Embedded Software Integration Engineer Specialisation: AUTOSAR | Embedded Linux | RTOS | Automotive Software Verification Experience: Relevant professional experience in embedded software integration and verification Engagement: IT Consulting Assignment About the Assignment Hykmann Global Business Solutions AB is looking for an experienced Embedded Software Integration Engineer for an exciting consulting assignment within automotive platform software development and verification. You will work as part of a platform engineering team responsible for developing, integrating and verifying software components across automotive Electronic Control Units (ECUs) and High-Performance Computing (HPC) platforms. The software environment includes AUTOSAR-based components, RTOS-based platforms, and graphical systems running on Yocto Linux and Qt/QML. The role involves close collaboration with software developers, system architects and Tier 1 suppliers to ensure robust integration, functionality and quality of embedded platform software. Key Responsibilities Develop, maintain and execute test plans for embedded platform software components. Design and implement automated test cases for unit-level and integration-level verification. Verify software functionality across ECUs, HPC platforms and associated embedded systems. Perform software integration testing and validation in simulation environments, test benches and vehicles. Collaborate with developers, architects and project stakeholders to define verification strategies. Conduct root-cause analysis of test failures and coordinate issue resolution with development teams. Work with automotive communication protocols and interprocessor communication interfaces. Document test results, prepare verification reports and maintain requirements traceability. Work closely with Tier 1 suppliers to coordinate software integration and verification activities. Contribute to continuous improvement of testing processes, automation and verification methodologies. Required Skills & Experience Experience in embedded software integration, testing and verification within the automotive industry. Strong programming skills and experience in software test automation. Good knowledge of .NET and Vector CANoe configuration. Experience with automotive communication protocols, including: CAN and LIN Ethernet and VLAN DoIP SOME/IP STOMP Experience with embedded Linux and Real-Time Operating Systems (RTOS). Familiarity with AUTOSAR-based software architectures and ECU platforms. Experience with unit testing and integration testing. Ability to analyse complex software issues and perform root-cause investigations. Good communication and collaboration skills, particularly when working with external suppliers. Additional Technical Exposure Experience with the following technologies and tools will be highly beneficial: Yocto Linux Qt/QML QNX Operating System Hypervisors Jenkins and CI/CD pipelines Google Test SystemD NetSim Hardware test benches and vehicle-level verification environments High-Performance Computing (HPC) platforms What We’re Looking For We are looking for a technically skilled and proactive engineer who enjoys working with complex embedded software platforms, system integration and automotive verification. The ideal candidate should be comfortable taking ownership of testing activities, collaborating across engineering teams and suppliers, and driving software quality throughout the development lifecycle. Interested in This Opportunity? If you have the relevant experience and are interested in exploring this assignment, we would be happy to connect with you.
