About the job Build the software that validates Graphcore’s machine learning stack, from frameworks to AI accelerator hardware. You’ll design production-quality test infrastructure that engineers can extend, maintain and rely on as Graphcore’s ML software grows. Your work will help teams deliver reliable products, with clear evidence of numerical accuracy and performance across the stack. You’ll architect scalable test frameworks and build CI/CD pipelines that run across simulators, emulators and physical hardware. You’ll create representative ML workloads, analyse their execution and turn the results into practical improvements to testing and tooling. This role gives you scope to shape software architecture and developer experience, not just add tests to existing systems. You’ll deepen your understanding of the AI compute stack while solving engineering problems that connect software design with hardware behaviour. The team and culture Graphcore’s ML QA engineers build automation, work with industry-standard frameworks and models, and contribute to upstream open-source projects. You’ll work across software teams, using code and design reviews to strengthen quality, security and maintainability. You’ll use workload results to challenge assumptions and guide technical decisions about how Graphcore tests its ML stack. You’ll own improvements, act quickly on testing gaps and mentor junior engineers to raise the team’s technical standards. What we’re looking for • Strong Python skills, demonstrated through designing, developing and maintaining production-quality software. • Software design and architecture skills for large, complex codebases, with a focus on testability and long-term maintainability. • Experience building CI/CD pipelines and automated testing systems in Linux environments. • Familiarity with C or C++, including the ability to read, debug and reason about low-level code. • The ability to mentor junior engineers and influence engineering practices through constructive feedback. • A self-directed approach to solving complex problems, identifying gaps and driving improvements. While we have outlined a set of requirements, we value transferable skills and diverse experiences. We also welcome engineers returning to the profession after a career break, including through returnship routes.
