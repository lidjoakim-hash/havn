Integration specialist

Quest Consulting Sverige AB · Stockholm, Sweden

💰 ca. 520 000–640 000 SEK/år (estimat · vanlig lønn, ikke bekreftet)Heltidvia ArbetsförmedlingenFrist 30.11.2026

Søk på stillingenÅpne i Havn (lagre, sammenlign, KI-hjelp)

Assignment description We are looking for an experienced API Manager Administrator with strong integration development experience to take ownership of the design, implementation and operation of an API and integration ecosystem. In this role, you will build and manage APIs, administer the API Manager platform and ensure secure and reliable connectivity between internal systems, external partners and AI/LLM services across on-prem and Azure environments. You will work with API development, integration flows, platform administration, security and infrastructure, as well as MCP-based integrations. You will design, develop and maintain REST, SOAP and GraphQL APIs and integration flows, implement message transformation, orchestration and routing, and develop reusable integration components such as policies, mediations and templates. The role also includes building and integrating MCP servers and tools that expose business capabilities to LLM-based clients. You will administer the API Manager platform across development, test and production environments, manage the API lifecycle and governance policies, integrate identity and key management providers and monitor API performance, throughput and reliability. You will also work with API Manager on Linux VMs and API workloads in Azure AKS, including scaling, ingress, networking and observability. Qualifications You have 4+ years of hands-on experience with API Management platforms. You have proven experience designing and implementing APIs and integration flows. You have strong understanding of API Manager components such as Gateway, Publisher, Developer Portal, Key Manager and Traffic Manager. You have experience integrating identity and key management providers with API Manager. You have experience running API Manager on Linux VMs, including databases, load balancers and high availability. You have working knowledge of Azure AKS, including kubectl, Helm, ingress, VNET and monitoring. You are familiar with LLM APIs, including requests, tokens, streaming, rate limits and governance. You have strong understanding of MCP architecture, security and troubleshooting. You have solid knowledge of OAuth2, JWT, API security and certificate management. You have Linux system administration skills. Meritorious API Manager certifications. Experience with Identity Server or microservices-based integration solutions. Experience with Terraform or Bicep for Azure provisioning. Knowledge of API monetization and subscription models. Experience with custom mediators, synapse configurations or policy extensions. Experience developing MCP servers using TypeScript, Python or Java. Exposure to AI/ML integration patterns and tool-use protocols. Swedish language skills.
