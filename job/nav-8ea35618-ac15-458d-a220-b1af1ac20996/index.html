Gjennom effektiv ressursbruk i offentlig sektor kan vi løse enda flere oppgaver for fellesskapet og støtte opp om viktige samfunnsmål. Dette er kjernen av samfunnsoppdraget vårt i DFØ! For å realisere visjonen om effektiv ressursbruk i offentlig sektor jobber vi langs mange spor, og nå søker vi deg som vil bli med på laget.  Dataanalytiker Målet for DFØ er effektiv ressursbruk i staten. Nå søker vi deg som ønsker å bruke data, analyse og teknologi til å utvikle kunnskapsgrunnlaget for bedre offentlige anskaffelser.   Som analytiker/datascientist vil du arbeide med data fra blant annet konkurransedokumenter i eForms format fra Doffinplattformen, spørreundersøkelser og regnskapsdata. Du vil bidra til å utvikle statistikk, analyser, dashboards og andre datadrevne produkter som brukes av offentlige virksomheter og beslutningstakere. Arbeidet vil ha et særlig fokus på datatilrettelegging for analyse,  og bruk av moderne teknologi som dataplattform, semantiske modeller, Power BI og kunstig intelligens.   Du vil samarbeide tett med både fageksperter og teknologimiljøer, og bidra til å utvikle nasjonale analyse- og statistikkprodukter som gir bedre beslutningsgrunnlag for offentlig sektor.   DFØ er offentlig sektors fagorgan for anskaffelser. Vi utvikler statistikk, analyser og digitale verktøy som gir innsikt i hvordan offentlige anskaffelser gjennomføres, og hvilke effekter de har på blant annet klima, innovasjon, effektivisering og digitalisering.   Stillingen er plassert i seksjon for analyse og innkjøpsledelse i divisjon for offentlige anskaffelser, som har ansvar for statistikk, analyse og innsikt på tvers av divisjonen.   Sentrale arbeidsoppgaver vil være å:• strukturere, bearbeide og kvalitetssikre data fra ulike kilder slik at de kan brukes til analyse og statistikk • bruke statistiske metoder og programmeringsverktøy som R, Python, SQL eller tilsvarende • utvikle og teste modeller og metoder for analyse, prediksjon, klassifisering og evaluering av tiltak • utforske hvordan kunstig intelligens og språkmodeller kan brukes til å analysere strukturerte og ustrukturerte data • visualisere og formidle komplekse analyser om anskaffelser på en forståelig og relevant måte • bidra til å dokumentere datagrunnlag, analysemetoder og statistikkprodukter • samarbeide med fagmiljøer, teknologimiljøer og andre analysefunksjoner om å utvikle datagrunnlag og nye analysemuligheter • bidra til å videreutvikle metoder, verktøy og arbeidsprosesser Det kan være aktuelt å tilpasse stillingens ansvar og innhold ut ifra din kompetanse, erfaring og interesse.  Kvalifikasjonskrav Vi søker deg som
