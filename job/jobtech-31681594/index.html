🚀 We’re Hiring: Embedded Software Application Engineer – Expert | Test Automation & Camera Systems Company: Hykmann Global Business Solutions AB Role: Embedded Software Application Engineer – Expert Specialisation: Test Automation | HIL/SIL | .NET | CANoe | Camera-Based Systems Industry: Automotive & Embedded Software Engagement: IT Consulting Assignment About the Assignment Hykmann Global Business Solutions AB is looking for an experienced Embedded Software Application Engineer at Expert level for an exciting consulting assignment within automotive software development and test automation. You will contribute to developing and enhancing test capabilities for an advanced test automation framework used to verify Human-Machine Interface (HMI) features and image processing pipelines in camera-based solutions designed for driver and human visibility. The role combines software development, test automation, system verification and hands-on testing in Hardware-in-the-Loop (HIL) and Software-in-the-Loop (SIL) environments. Key Responsibilities Develop and enhance test automation capabilities for embedded automotive software. Build and maintain automated testing solutions for HMI features and camera-based image pipelines. Design, implement and execute automated test cases to verify software functionality and system performance. Perform verification and validation activities in HIL and SIL environments. Conduct manual verification when required. Set up, configure and troubleshoot test rigs and verification environments. Analyse test results, investigate failures and support root-cause analysis. Work with automotive communication protocols and CANoe configurations. Collaborate with software developers, system engineers and verification teams to improve test coverage and overall software quality. Contribute to the continuous improvement of test automation frameworks and verification methodologies. Required Skills & Experience Strong programming and software development skills. Proven experience in test automation and automated verification. Hands-on experience with .NET development. Good knowledge of Vector CANoe configuration. Strong understanding of automotive communication protocols. Good understanding and practical experience of HIL and SIL testing environments. Experience in software testing, verification and validation within embedded or automotive systems. Ability to perform manual testing and work hands-on with test rig setup and configuration. Strong analytical and troubleshooting skills. Meritorious Experience Previous experience in the following areas will be a significant advantage: Camera Monitor Systems (CMS). Automotive vision cameras and camera-based solutions. Image processing and image pipeline verification. Automotive infotainment systems. HMI development and verification. Camera-based driver visibility and monitoring applications. Advanced automotive test automation frameworks. What We’re Looking For We are looking for an expert-level engineering professional who combines strong programming capabilities with practical experience in automotive software test automation. The ideal candidate should be comfortable working across software development and verification activities, independently driving technical solutions, troubleshooting complex issues and contributing specialist knowledge to the engineering team.
