Veritaz is a leading IT staffing solutions provider in Sweden, committed to advancing individual careers and aiding employers in ensuring the perfect talent fit. With a proven track record of successful partnerships with top companies, we have rapidly grown our presence in the USA, Europe, and Sweden as a dependable and trusted resource within the IT industry. Job Overview Role Summary An experienced DevSecOps Engineer is needed for a product development organisation focused on integrating cybersecurity throughout the development, testing, and delivery lifecycle of embedded software. The role works closely with engineering teams to automate security controls, improve secure software delivery practices, and strengthen product security across the full lifecycle. Key Responsibilities Develop, maintain, and improve CI/CD pipelines for embedded software development and delivery. Integrate automated security testing, code analysis, and security controls into development workflows. Implement and improve processes for vulnerability management and secure software delivery. Support embedded software developers with secure coding practices and security-focused development guidance. Contribute to Cyber Resilience Act (CRA) readiness activities and security documentation. Collaborate with development and test teams to embed security considerations early and continuously in the product lifecycle. Technical Stack & Requirements Hands-on experience with DevOps or DevSecOps practices. Strong knowledge of Linux, Git, and CI/CD pipelines. Experience with Jenkins and/or GitLab CI. Programming skills in Python and/or C/C++. Understanding of embedded systems and software security. Experience with automated security testing and code analysis, including SAST and DAST, is advantageous. Experience with Yocto, SBOMs, Secure Boot, and vulnerability management is advantageous. Qualifications & Experience The ideal candidate has practical experience in DevOps or DevSecOps roles and is comfortable working in an embedded software product-development environment. A solid understanding of software security and embedded systems is required. Experience with IEC 62443 and contributing to CRA-related security documentation is considered beneficial.
