Avdeling Infrastruktur drift har ansvar for å sikre en stabil, sikker og fremtidsrettet teknisk grunnplattform for Bærum kommune. Avdelingen drifter og forvalter nettverk, datasenter, server- og plattforminfrastruktur, identitet, operasjonell sikkerhet og fysisk IT-infrastruktur, samt gjennomfører nødvendige moderniserings- og sikkerhetstiltak. Vi søker en erfaren og engasjert medarbeider innen IT-nettverk og nettverksarkitektur. Rollen krever solid teknisk erfaring fra større og komplekse IT-miljøer, kombinert med god arkitekturforståelse. Vårt tekniske fagmiljø omfatter blant annet Fortinet, Cisco, Microsoft Active Directory (AD), Entra ID og Cisco Identity Services Engine (ISE). Vi ser derfor etter deg som forstår hvordan nettverk, sikkerhet, identitet og tilgangskontroll spiller sammen. Arbeidsoppgaver • Drift, forvaltning og videreutvikling av LAN, WAN og WiFi • Design og videreutvikling av nettverksarkitektur • Cisco og Fortinet switching/routing • Fortinet brannmur- og sikkerhetsløsninger • Cisco ISE, Network Access Control (NAC) og 802.1X • Integrasjon mellom Cisco ISE og Microsoft Active Directory • Autentisering, autorisering og policybasert nettverkstilgang • Segmentering og mikro segmentering • VPN og sikker ekstern tilgang • Redundans og høy tilgjengelighet • DNS, DHCP og IP-adressering • Nettverksovervåkning, logging og feilsøking • Standardisering og automatisering av nettverksdrift • Teknisk dokumentasjon, løsningsdesign og arkitekturbeskrivelser • Teknisk rådgivning i prosjekter og ved større endringer Kvalifikasjoner • Relevant høyere utdanning innen IT, nettverk, sikkerhet eller tilsvarende er ønskelig.
