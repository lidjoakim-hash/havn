Cloud Platform & DevOps Engineer

Integro Consulting AB · Göteborg, Sweden

Søk på stillingenÅpne i Havn (lagre, sammenlign, KI-hjelp)

Work description: We are looking for a Cloud Platform & DevOps Engineer with 5+ years of experience to own the infrastructure, security and automation of our AWS Virtual Engineering Workbench (VEW). VEW is a serverless self-service platform that lets our engineers launch secure, cloud-based development environments on demand. You will run and extend it, and work with our engineering teams to bring automotive toolchains such as MATLAB/Simulink, AUTOSAR tooling, compilers and simulators into the cloud. Prior experience with VEW itself is not required. We are looking for strong hands-on experience with the AWS services it is built on. Responsibilities: Deploy, operate and evolve the VEW backend using infrastructure as code Maintain the self-service catalog of virtual workstations (Amazon DCV) and engineering environments Automate the AMI lifecycle for engineering toolchains Integrate VEW with identity (Microsoft Entra ID), license servers and code repositories Build CI/CD pipelines for the platform and for the teams that use it Work with our platform engineers to manage floating licenses for specialized tools Skills & Experience required: 5+ years building and operating production workloads on AWS Infrastructure as code: AWS CDK, Terraform or similar Serverless on AWS: Lambda, API Gateway, DynamoDB, Step Functions, EventBridge Python AWS multi-account setup and security: Organizations, IAM, cross-account access, VPC networking Identity federation with Amazon Cognito and an enterprise identity provider (Entra ID / Active Directory) AWS Service Catalog and EC2 Image Builder (or Packer) CI/CD with GitHub Actions or AWS CodePipeline You have prior work experience from the automotive industry Degree in SW/IT or similar Fluent in English is a must and Swedish is a plus A plus if you have: Hands-on experience with AWS Virtual Engineering Workbench Automotive industry background Packaging R&D toolchains (MATLAB/Simulink, AUTOSAR, cross-compilers) into AMIs or containers FlexNet/FlexLM or other floating-license server administration SIL test pipelines, and connecting cloud pipelines to HIL rigs Virtual ECUs, vehicle environment models, or MBSE tooling Amazon DCV, Windows and Linux image hardening Softskills: You are flexible and pro-active and driven You are communicative and can easily create a network You enjoy teamwork and working cross-functionally
