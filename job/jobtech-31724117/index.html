You will work with digital twins, model-based development and real-time simulation technologies to support early-stage verification and validation of complex technical systems before physical prototypes are developed. The role combines software development, system architecture, sensor modelling, simulation engineering and AI-driven automation. You will collaborate closely with hardware engineers, software developers and system integration teams to develop reliable and scalable simulation solutions. Key Responsibilities 1. Sensor Simulation & Digital Twin Development Design and develop virtual models of complex sensor systems. Simulate sensor algorithms, signal processing and associated hardware components. Develop digital twins to replicate real-world system behaviour and operating conditions. Implement model-based development approaches for complex technical systems. Improve simulation accuracy, reliability and performance. 2. Simulation Environments – HIL / SIL Design, develop and maintain integrated simulation environments. Implement Hardware-in-the-Loop (HIL) and Software-in-the-Loop (SIL) solutions. Develop simulation chains for early verification and validation of new concepts. Conduct simulation-based performance, robustness and functional testing. Ensure simulation environments accurately represent real-world operating conditions. Support seamless integration between virtual simulations and physical products. 3. AI-Driven Automation & Software Development Automate testing, simulation and analysis processes using AI-powered code agents. Develop scripts and customized tools to improve engineering productivity. Implement automated test frameworks and analysis workflows. Integrate AI-assisted development tools into simulation and verification processes. Provide rapid feedback on system performance, reliability and security. 4. Simulation Infrastructure & DevOps Develop and maintain scalable simulation infrastructure. Implement container-based simulation environments. Support cloud-based engineering workflows. Develop and maintain CI/CD pipelines for automated simulation and testing. Ensure traceability, reproducibility and reliability of simulation deliveries. Contribute to continuous improvement of development and deployment processes. 5. Cross-Functional Engineering Collaboration Collaborate with hardware, software and system integration teams. Translate complex technical requirements into simulation models and software solutions. Support integration, verification and validation activities. Share technical knowledge and contribute to engineering best practices. Promote model-based engineering and continuous improvement initiatives. Required Skills & Experience Relevant university degree in Systems Development, Computer Science, Mechatronics, Engineering or an equivalent technical discipline.
