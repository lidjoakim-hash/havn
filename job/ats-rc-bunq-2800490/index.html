At bunq, we’re on a mission to Make Life Easy for our users by creating the most user-centric banking experience out there. Our paid marketing campaigns run on predictions about which new users will turn out to be valuable. This role makes sure those predictions are right. That’s where you come in. As our Data Scientist, Marketing, you’ll own the machine learning models that predict the value of every newly verified user and feed that value into Google Ads, so our campaigns find more users like them. If the models are off, the spend is off. AI can help you write and debug code, but it can’t build the model or judge whether the output can be trusted. That judgment is yours. Take Ownership 🚀 You’ll own the predictive models that steer our marketing spend. Here’s how you’ll do it: • Build, maintain and expand the predictive models for marketing, from first idea to production, starting with the models that predict each new user’s value in their first 90 days. • Hit the model quality targets within 9 months: a Spearman rank correlation of 0.50 or higher and a binary model AUC of 0.75 or higher. • Keep the models running in production and monitor data and model health to find where to intervene, using Claude Code to move faster and validating everything it produces. • You’ve built predictive models with traditional machine learning, such as XGBoost. • You’ve written Python and built the data pipelines a model needs, including when none existed. • You’ve shipped ML models to production and kept them running. • You’ve done deep dives into data and model health to find what needs intervention. • You use AI tools like Claude Code in your daily work and know where they stop. • You are fluent in English. Curious to see how we make life easy? - try the bunq app, it only takes 5 minutes to sign up.
