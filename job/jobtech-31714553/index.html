Step into a key role with our customer, where you will design critical Python tooling and GitHub workflows that empower engineering teams and streamline Azure data platforms. About the role As a Senior Software Engineer, you will focus on Python development, developer productivity, and CI/CD automation. You will take ownership of technical solutions, helping connect reliable engineering practices with data workflows. You are offered A hands-on consultancy assignment offering the opportunity to drive developer productivity. Work with modern cloud technologies. Collaborate with highly skilled engineering teams. Work tasks This role focuses on building tools, CI/CD pipelines, and reusable workflows that improve how engineering teams develop and deliver software. Design, build, and maintain production-level Python tooling for engineering and automation. Develop GitHub Actions and reusable workflows for consistent team adoption. Improve CI/CD practices across Windows and Linux to support reliable delivery. Support Azure-centered data workflows involving Databricks, Spark, and Kafka. Implement data quality checks and schema enforcement within data platforms. Translate complex stakeholder needs into structured, maintainable technical solutions. We are looking for you who have Advanced knowledge of Python development for building production-grade tooling. Good knowledge of GitHub Actions and reusable automation patterns. Good knowledge of Docker in everyday development. Basic knowledge of Azure data platforms and technologies like Databricks, Spark, or Kafka. EU citizenship. It is meritorious if you have Basic knowledge of GitHub REST and GraphQL APIs, GitHub CLI, or self-hosted runners. Basic knowledge of package and artifact management, including JFrog Artifactory. Basic knowledge of Bash and PowerShell scripting. Basic knowledge of data governance, data modeling, Git LFS, or machine learning deployment. To succeed in the role, your personal skills are: Supportive Goal oriented Responsible Intellectually curious Our recruitment process This recruitment process is handled by Academic Work and it is our client’s wish that all questions regarding the position is directed to Academic Work. Our selection process is continuous and the advert may close before the recruitment process is completed if we have moved forward to the next phase.
