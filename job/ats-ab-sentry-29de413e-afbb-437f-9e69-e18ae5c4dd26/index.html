ABOUT SENTRY Software runs the world and the pace is faster than ever. Sentry helps developers fix errors and performance issues before users notice, so teams can spend less time firefighting and more time building. Trusted by 200,000+ organizations, Sentry is today’s application monitoring standard and our team is building its AI-native future. ABOUT THE ROLE You’ll join the team behind Sentry’s Size Analysis and Snapshots, two products that check every pull request before it ships. Size Analysis breaks down iOS and Android builds to explain why an app got bigger. Snapshots catches unintended visual changes by diffing screenshots against a baseline. Both run in our customers’ CI, report straight to Source Code Management providers, and handle some of the heaviest payloads at Sentry: multi-GB app binaries and builds with tens of thousands of images. IN THIS ROLE YOU WILL You’ll work full-stack with a backend lean, owning features from the moment a build arrives from CI, to the moment when UI engineers use that data to decide whether to merge. You’ll own the codebase behind our mobile binary analysis and large-scale image comparison. You’ll share the pipeline, the GitHub integration and on-call with the rest of the Sentry team. - Build and tune the backend services and task-based pipelines that ingest, analyze and compare builds, with large artifacts in object storage, fast and reliable on multi-GB binaries and changesets with tens of thousands of screenshots - Extend our product: own the functionality end-to-end, react on feedback and come up with proposals for further product development. - Own the GitHub integration end to end: PR status checks, comments, approvals and webhooks, including races, duplicates and missing-baseline edge cases - Ship frontend features such as treemaps, build comparisons and diff viewers that stay fast on huge datasets - Run what you build: deploys across regions, metrics, logging and on-call, and be the person who debugs the weird customer build YOU’LL LOVE THIS JOB IF YOU - Want your work to show up in the pull requests our customers open every day, not buried in a dashboard nobody checks - Like problems with real weight: a multi-GB IPA, tens of thousands of screenshots in a single build, a binary format with sparse documentation - Would rather own a feature from upload to UI than hand off half of it (end-to-end ownership) - Enjoy building for developers, who will tell you exactly what’s wrong and why - Want to help two products that started at a startup grow into core parts of Sentry QUALIFICATIONS - 3+ years building production web services, with strong Python (Django preferred) and a habit of typed, tested code - Working proficiency in React and TypeScript, enough to ship a full feature without handing off the frontend - Experience with async task systems and event pipelines (Kafka, task queues, worker pools), including idempotency, locking, retries and their failure modes - Experience with Postgres schema design and migrations that work under rolling deploys, plus pragmatic rollout habits like feature flags and revertable changes - A track record of performance work: profiling, parallelism, memory reduction and large-file streaming through object storage - Bonus points for: - Hands-on experience with mobile build artifacts and tooling (LIEF, bundletool, apksigner, link maps, DWARF, code signing) -
