Senior Software Engineer Python, GitHub-automation & dataplattformar Lund

NDP IT AB · Lund, Sweden

Søk på stillingenÅpne i Havn (lagre, sammenlign, KI-hjelp)

Om uppdraget Vi söker nu en Senior Software Engineer med fokus på Python, GitHub-automation och dataplattformar för ett uppdrag i Lund. Här bygger du verktyg och flöden som hjälper andra utvecklare att göra sitt bästa arbete: Python-verktyg som tar bort repetitiva moment, återanvändbara GitHub-workflows som gör leveranser mer konsekventa och datakvalitetskontroller som fångar fel innan de sprids vidare. Rollen kombinerar mjukvaruutveckling, utvecklarproduktivitet och stöd till dataplattformar. Uppdraget sker på plats i Lund med planerad start 2026-12-15. Arbetsuppgifter Bygga Python-verktyg av produktionskvalitet som automatiserar utvecklingsuppgifter och minskar manuellt arbete Utveckla GitHub Actions och återanvändbara workflows som ger teamen enhetliga och underhållbara sätt att bygga och leverera Stötta Azure-baserade dataflöden med tekniker som Databricks, Spark och Kafka, inklusive datakvalitetskontroller Förbättra CI/CD i både Windows- och Linuxmiljö med fokus på spårbarhet och teknisk kvalitet Ta lösningar från otydliga krav till fungerande kod, med genomtänkta beslut kring scope, design och underhållbarhet Samarbeta nära utvecklare och intressenter för att identifiera förbättringsbehov Vi söker dig som har Gedigen erfarenhet av Python-utveckling för verktyg och automation i produktion Praktisk erfarenhet av GitHub-automation, inklusive Actions och återanvändbara workflows Erfarenhet av Azures dataplattformar och tekniker som Databricks, Spark, Kafka eller schemahantering God vana av Docker i det dagliga utvecklingsarbetet Förmåga att arbeta självständigt, ställa rätt frågor och ta ansvar för helheten EU-medborgarskap (krav för uppdraget) Meriterande GitHub REST/GraphQL API och GitHub CLI Self-hosted runners eller GitHub Enterprise Server JFrog Artifactory och pakethantering Bash och PowerShell Data governance, datamodellering, Git LFS eller ML-driftsättning Övrigt Du behöver inte kunna alla verktyg i listan. Vi tror att du bryr dig om dem som använder det du bygger, skriver tydlig kod och väljer lösningar som passar problemet. Skicka CV och några rader om dig till info@ndpconsult.se.
