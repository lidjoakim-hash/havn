The Role: Here at Neo4j, we're on the lookout for a software engineer to join our Core Networking Engineering Team, where you will primarily work on the Neo4j network server modules. There will also be scope to work on the drivers and their APIs as well as our proprietary binary protocol. The drivers act as an adapter between the network and client applications. The server modules manage the server side of the conversation, using both HTTP and our binary protocol, Bolt. Drawing on your deep understanding of network concepts and binary protocols, you will be a key part of influencing the strategic direction for connectivity with Neo4j and the drivers together with our product managers. You will be leading the design of new features and improvements to the protocol whilst taking on feedback from other experts and stakeholders within the company. You will then implement these designs in the server codebase. As well as software development, you will also have the opportunity to do things like supporting community projects, writing blog posts, and helping with training and other events. What You'll Need: We're looking for 5+ years of practical experience in: • A modern general-purpose or systems programming language and its ecosystem (e.g., Java, Go, Rust, C, C++) You will ideally have experience and/or an interest in: • Network development (binary protocol specs like Bolt, Frontend/Backend, MongoDB Wire Protocol) • Network packet analysis (e.g., Wireshark) • Distributed system design • API design • Asynchronous network frameworks (e.g., Netty or similar) • Customer experience and developer community interaction • Concurrency and asynchronous programming You may have also worked with some of: • Database management systems • Graph Databases • HTTP and web service development • Docker • System-oriented languages such as: C, C++, Rust or Go #LI-Hybrid Why Join Neo4j?
