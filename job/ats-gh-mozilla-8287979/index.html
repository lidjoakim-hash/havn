Required qualifications • Substantial experience in a browser-engine codebase or in automating for a browser-engine, ideally Firefox/Gecko. • Solid Javascript and applying that language skill to write automated tests. • Proficiency in and experience developing software in C++. • Strong debugging skills in a mature larget codebase. • Comfort working in the open: public bugs, code review, and upstream landing. Preferred • Prior contributions to Gecko or another major browser engine. • Familiarity with web standards and Web Platform Tests.
