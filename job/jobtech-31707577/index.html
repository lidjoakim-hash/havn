API Manager Administrator with Integration Developer Experience

Avaron AB · Solna, Sweden

About the Company At Avaron, you get the security of permanent employment combined with the variety of working at different customers. We place specialists across everything from tech, IT and industry to project management and business support – and whatever the assignment, you have a consultant manager who is there for you and your development. About the Role Every API and integration in this ecosystem has to be secure and reliable, and the work is getting more demanding as AI services join the mix. You will own the design, implementation and operations of the API and integration layer, connecting internal systems, external partners and LLM services across on-premises and Azure environments. What makes this role stand out is the mix of classic integration work and new AI and MCP-based connectivity, with real ownership over how the platform is built and run. The assignment is based in Solna. Job DescriptionYou design, build and maintain REST, SOAP and GraphQL APIs and integration flows, including message transformation, orchestration and routing. You create reusable integration components such as policies, mediations and templates. You build and integrate MCP servers and tools that expose business capabilities to LLM-based clients, and you design robust error handling, retries and resiliency patterns. You administer API Manager across development, test and production, and configure the Gateway, Publisher, Developer Portal, Key Manager and Traffic Manager. You manage the API lifecycle, from design and versioning to publishing and deprecation, and set the governance policies that go with it. You integrate identity and key management providers such as Keycloak, Okta or Curity. You install and maintain API Manager on Linux VMs, including database setup, load balancing and high availability. You run API workloads on Azure AKS, covering Helm, scaling, ingress, networking and observability. You onboard and govern LLM APIs such as OpenAI, Azure OpenAI and Anthropic through the gateway. You monitor and optimize API performance, throughput and reliability. You apply API security best practices and secure-by-design patterns for APIs and MCP endpoints. You document APIs, integration flows and platform configurations, and maintain runbooks. You collaborate with development, security, AI/ML and infrastructure teams on shared solutions. RequirementsAt least 4 years of hands-on experience with API management platforms. Proven experience designing and implementing APIs and integration flows. Strong understanding of API Manager components: Gateway, Publisher, Portal, Key Manager and Traffic Manager. Experience integrating identity and key management providers with API Manager. Experience running API Manager on Linux VMs, including databases, load balancers and high availability. Working knowledge of Azure AKS, including kubectl, Helm, ingress, VNET and monitoring. Familiarity with LLM APIs, including requests, tokens, streaming, rate limits and governance. Strong understanding of MCP architecture, security and troubleshooting. Solid knowledge of OAuth2, JWT, API security and certificate management. Linux system administration skills. Nice to haveAPI Manager certification. Experience with Identity Server or microservices-based integration solutions. Terraform or Bicep experience for Azure provisioning. Knowledge of API monetization and subscription models. Experience with custom mediators, Synapse configurations or policy extensions. MCP server development in TypeScript, Python or Java. Exposure to AI/ML integration patterns and tool-use protocols. Swedish language skills.
