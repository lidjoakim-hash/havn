Vill du arbeta med systemutveckling och har erfarenhet inom antingen Java eller Microsofts .NET-miljö? Vi söker nu kompetenta profiler till vår kandidatpool inför kommande konsultuppdrag! Vi söker dig som har erfarenhet av systemutveckling med kunskap inom antingen Java eller Microsofts .NET-miljö. Vi bygger just nu upp en kandidatpool med konsulter inför kommande uppdrag hos våra kunder. Det här är därför inte en annons för en specifik tjänst eller en pågående rekryteringsprocess, utan en möjlighet för dig att anmäla ditt intresse för framtida konsultuppdrag inom området. Systemutvecklare – Java eller .NET/C# Vi söker dig som har erfarenhet av systemutveckling inom antingen Java eller Microsofts .NET-miljö (C#) och som vill arbeta med att utveckla, vidareutveckla och underhålla applikationer och IT-system. I rollen arbetar du med att ta fram och implementera tekniska lösningar utifrån verksamhetens behov. Arbetsuppgifterna kan bland annat omfatta programmering, webbutveckling, integrationer och databashantering samt testning, felsökning, dokumentation och kvalitetssäkring av kod. Beroende på din tekniska inriktning kan arbetet exempelvis innefatta utveckling i Java eller C#/.NET, arbete med ASP.NET, REST API:er och webbtjänster samt databaser som SQL Server. Erfarenhet av utvecklingsverktyg och ramverk som Visual Studio, Maven och MVC samt testdriven utveckling är också relevant. Systemutvecklare Java - Kvalifikationer Kunskaper och erfarenhet inom JAVA. Dokumenterad utbildning inom JAVA och kunna hålla utbildning inom området. Systemutvecklare .NET - Kvalifikationer Kunskaper inom .NET samt både C# och Visual Basic och erfarenhet som motsvarar de olika kompetensnivåerna. Djupa kunskaper om Web-utveckling med ASP. Net. Kunskap och erfarenhet av Microsoft Sharepoint, databaser (primärt SQL Server) och Microsoft BizTalk Server.
