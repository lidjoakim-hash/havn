UNLEASH AI INNOVATORS, SECURELY Software is being rewritten in real time. AI agents are starting to write more code than humans do, at a speed no security team has ever had to match, and that single shift is opening up the biggest opportunity our industry has seen in a decade. We're not bracing for it, we're building the company that owns it. Snyk is building the next generation security platform where security isn't a set of tools people operate. It's a team of security agents working alongside your engineers, finding, fixing, and governing risk at the speed software is now built. These agents work alongside both the company build and the agents they adopt. Security stops being a queue of work waiting for people, and becomes a coordinated workforce companies direct and trust. Why this role? AI agents now write, review and ship a growing share of the world's software. That changes how engineering teams work, and it changes what "secure" means. At Snyk, we're building a new AI-native security platform from the ground up. It's built for a world where engineering and security teams hand work to agents, work alongside them, and need to trust what comes back. As a Staff Product Designer, you'll work with product, engineering and security research to define that platform. That means shaping how people and agents work together, and helping make security part of the engineering workflow rather than a step that slows it down. This role is for you if you care about making software safer, you're curious about how engineering is changing with AI, and you want to help decide what comes next rather than react to it. What you'll do - Own design end to end for a zero-to-one AI security product: problem framing, research, interaction model, and shipped UI. - Set the direction for the agent experience: how security and engineering teams hand off work to agents, follow progress, step in, and approve what agents produce. - Define AI interaction patterns (agent actions, confidence, explanations, human-in-the-loop controls) that earn developers' trust. - Design for where developers actually work: CLI, IDE, pull requests, and AI coding agents, as well as the web. - Frame problems nobody has named yet. Research strategic questions, not just usability ones, and write up answers product and engineering can act on. - Model the system: agents, workflows, policies, findings and fixes, and how they relate. Name the gaps between teams instead of working around them. - Prototype in code with AI tools (e.g. Claude Code, Cursor), explore many directions quickly, and test with real users within days. - Ship production code alongside engineering: raise PRs with code from a coding agent, using our design system components, instead of handing off static files. - Lead workshops and sprints that align product, engineering and security research when the direction is unclear. - Raise the AI fluency of the wider design team through coaching, shared tools and example workflows. What you bring - 8+ years in product design, with significant time spent designing for developers: dev tools, security, cloud, infrastructure, or APIs. - A portfolio showing shipped work for technical users, including complex workflows and enterprise constraints. - End-to-end craft: interaction design, information architecture and visual polish, with the systems thinking to turn new patterns into reusable ones. You move between strategy and pixel-level detail. - An AI-native workflow you can show: working prototypes, tools or agents you've built with coding agents in the last 6 months and put in front of users, not just prompts. - Strong judgement on agent UX: when to automate and when to ask, how to show reasoning and uncertainty, how people review, approve and step in, and how to recover when an agent gets it wrong. - Clear storytelling with executives, engineers and customers alike. Nice to have - Domain experience in application security, software
