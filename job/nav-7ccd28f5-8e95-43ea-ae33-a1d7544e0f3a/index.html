Vil du jobbe med Microsoft 365, IT-sikkerhet og moderne IT-drift i et internasjonalt konsern?

RVM Systems AS · Drammen, Norway

RVM Systems styrker sitt globale IT-team og søker en erfaren IT System Engineer til kontoret i Kobbervikdalen i Drammen.    Du blir en del av et internasjonalt IT-team som samarbeider om drift, sikkerhet og videreutvikling av konsernets IT-løsninger. En viktig del av rollen er også å integrere nye selskaper og land i konsernets IT-miljø, inkludert onboarding av brukere, enheter og migrering mellom Microsoft 365-tenants.  Arbeidsoppgaver  Microsoft 365 og identitet: Administrere og videreutvikle Microsoft 365, Entra ID, Exchange Online og Microsoft Defender, inkludert Conditional Access og sikkerhetskonfigurasjon.  SharePoint og Teams: Forvalte og videreutvikle SharePoint og Teams, inkludert migrering av data fra tradisjonelle filservere til moderne skyløsninger.  Onboarding og tenant-migreringer: Integrere nye selskaper og land i konsernets IT-miljø, inkludert oppsett av brukere, lisenser, enheter og tilganger.  Windows Server og hybrid IT: Drifte Windows Server og Active Directory, håndtere hybrid identitet og bidra til overgang til skybaserte tjenester.  Endepunktstyring: Videreutvikle og administrere Intune og NinjaOne, med fokus på policyer, enhetssikkerhet, compliance, patching og fjernadministrasjon.  IT-sikkerhet: Følge opp sikkerhetshendelser og bidra til drift av databaser, nettverk og øvrige infrastrukturtjenester.  Øvrig systemdrift: Bidra til vedlikehold av databaseservere, drift av øvrige infrastrukturtjenester og oppfølging av nettverks- og sikkerhetsløsninger.  Teknisk støtte og dokumentasjon: Bistå internasjonale IT-kolleger, håndtere eskalerte supportsaker og dokumentere løsninger og rutiner i Confluence.  Hvem ser vi etter?  Vi ser etter deg som har:  • Solid praktisk erfaring med Microsoft 365 og Entra ID  • Erfaring med IT-drift og sikkerhet i Windows-miljøer  • Forståelse for Windows Server, Active Directory og hybrid identitet  • Relevant IT-utdanning eller tilsvarende arbeidserfaring  • Meget gode muntlige og skriftlige ferdigheter i norsk og engelsk  Erfaring med PowerShell, Microsoft Graph, SharePoint-migrering, Jira/Confluence, Linux-miljøer, NinjaOne eller Palo Alto er en fordel.  Vi tilbyr  • En fast 100 % stilling i et internasjonalt IT-team  • Varierte oppgaver innen skyteknologi, sikkerhet og infrastruktur  • Mulighet til å påvirke og videreutvikle konsernets IT-løsninger  • Arbeidssted i Drammen, med mulighet for noe hjemmekontor  Interessert?  Vil du bidra til å utvikle og sikre IT-miljøet i et internasjonalt konsern?
