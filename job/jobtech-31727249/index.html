Soros Consulting söker nu en Integration specialist till ett konsultuppdrag i Stockholm. Om uppdraget Vi soker en API Manager Administrator med stark integrationsutvecklingserfarenhet for att aga design, implementation och drift av kundens API- och integrationsekosystem. Rollen innebar att bygga och hantera API:er, administrera API Manager-plattformen, samt sakerstalla saker och tillforlitlig konnektivitet mellan interna system, externa partners och AI/LLM-tjanster (inklusive MCP-baserade integrationer) over on-prem- och Azure-miljoer. Arbetsuppgifter inkluderar design/utveckling/underhall av REST/SOAP/GraphQL-API:er, implementering av meddelandetransformation/orkestrering/routing, administration av API Manager over dev/test/produktion, konfiguration av Gateway/Publisher/Developer Portal/Key Manager/Traffic Manager, integration av identitetshanteringsleverantorer, installation/underhall pa Linux-VM, hantering av API-arbetsbelastningar pa Azure AKS, samt onboarding/styrning av LLM-API:er (OpenAI, Azure OpenAI, Anthropic) via gatewayen. Obligatoriska krav 4+ ars praktisk erfarenhet av API Management-plattformar Bevisad erfarenhet av att designa och implementera API:er och integrationsfloden Stark forstaelse for API Manager-komponenter (Gateway, Publisher, Portal, Key Manager, Traffic Manager) Erfarenhet av att integrera identitets-/nyckelhanteringsleverantorer med API Manager Erfarenhet av att kora API Manager pa Linux-VM (DB, lastbalanserare, HA) Arbetskunskap om Azure AKS (kubectl, Helm, ingress, VNET, monitorering) Kannedom om LLM-API:er (requests, tokens, streaming, rate limits, styrning) Stark forstaelse for MCP-arkitektur, sakerhet och felsokning Solid kunskap om OAuth2, JWT, API-sakerhet och certifikathantering Linux-systemadministrationsfardigheter Meriterande API Manager-certifieringar Erfarenhet av Identity Server eller mikrotjanstbaserade integrationslosningar Terraform eller Bicep for Azure-provisionering Kunskap om API-monetisering och prenumerationsmodeller MCP-serverutveckling med TypeScript, Python eller Java Uppdragsinformation Start: 2027-01-11 Slut: 2027-12-31 Omfattning: 100% (2 roller) Plats: Stockholm (SE) Lön: Enligt överenskommelse Sista ansökningsdag: 2026-11-16 Om Soros Consulting Soros Consulting AB tillsätter erfarna specialister inom energi, elkraft, säkerhet och samhällsviktig infrastruktur.
