About the Team The Enterprise team builds the control-plane capabilities that ClickHouse Cloud’s largest global customers—including financial institutions, enterprise fleets, and AI platforms—rely on to run mission-critical infrastructure at scale. We solve complex state orchestration, automated scheduling, and distributed system consistency problems across multi-region cloud environments. What You Will Do - Design scalable models to configure, validate, secure, and audit settings across thousands of enterprise organizations and services. - Build reliable control-plane orchestration workflows, such as automated scaling schedules, backup/restore mechanisms, and cross-region provisioning. - Ensure distributed system consistency across multi-tenant environments, building automated reconciliation and repair paths for partial failures. - Own features end-to-end: from backend API design (Node.js/TypeScript) through the Console UI, public APIs, and Infrastructure-as-Code (Terraform) support. What We Are Looking For - Experience: 6+ years in software engineering, with deep experience in cloud control planes, provisioning layers, or workflow engines. - Core Stack: Strong TypeScript and Node.js backend capabilities, with comfort shipping React UI and working with document/relational stores (PostgreSQL, MongoDB). - Control-Plane Mechanics: Hands-on experience building systems that manage desired vs. actual state, idempotency, retries, and scheduled jobs. - Cloud & Security Fluency: Familiarity with AWS/GCP IAM, cross-account access, encryption/KMS, and enterprise requirements like BYOC (Bring Your Own Cloud) or VPC peering. Ideal Backgrounds: Managed database/data platform control planes (e.g., MongoDB Atlas, Snowflake, Confluent Cloud, Elastic Cloud, CockroachDB) or developer platforms (e.g., Temporal, Vercel, Fly.io http://Fly.io, HashiCorp).
