What you’ll work on Help build the software that connects Graphcore hardware with the machine learning frameworks researchers and engineers rely on. You’ll implement features, optimise performance, resolve defects and create tests and technical documentation. Your team and support The Frameworks team works with tools including PyTorch and Triton Its work connects these tools with compilers, which translate code for hardware, and runtime software, which helps it execute. We plan and review work in short cycles using Scrum. You’ll have clear priorities, regular feedback and opportunities to learn from colleagues working across software and hardware. Technical evidence and the needs of our users help guide our decisions. You’ll be encouraged to ask questions, challenge existing approaches and share ideas for making things better. Take responsibility for your work and speak up when you spot a problem or need support. How you’ll learn and grow During the two-year programme, you’ll build your understanding of how software and hardware work together to run AI workloads.
