Soros Consulting is now looking for a System Engineer – Technical Authority for a consulting assignment in Stockholm. About the assignment Technical Authority (TA) role within a project delivering total naval combat systems solutions to the end customer, integrating systems and sensors into a system-of-systems solution. The TA manages the technical scope of an assigned domain, from capability definition and requirements to supplier selection, integration and verification, working closely with the Technical Project Manager. Required qualifications Formal degree in Engineering, or equivalent. Experience in requirements analysis and requirements management. Experience in working on a system of systems level. Experience in working with system/solution design. Experience with working in integrated project teams. Swedish citizenship is mandatory; must pass a security vetting based on current regulations around security protection. Nice to have Experience in the naval domain and/or defense industry. Experience in Naval Combat Systems. Experience in Weapon System Integration. INCOSE based Systems Engineering experience. Experience in managing sub-suppliers. Experience with customer based acceptance processes. Experience in technical and solution trade-off analyses.
