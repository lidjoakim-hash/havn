About the job As a Senior Software Engineer, you’ll develop, maintain and release the C++ libraries and runtime APIs that engineers use to build and execute workloads on Graphcore’s AI hardware. Your work will focus on developer-facing libraries, runtime components or a combination of both. You’ll design clear abstractions for low-level hardware capabilities, improve reliability and performance, and support developers integrating these libraries into the wider software stack. You will take ownership of library changes from design and implementation through review, integration, release and ongoing maintenance. Deliver dependable library releases through packaging, dependency validation, release notes and the maintenance fixes developers need. You’ll write API documentation, usage examples and migration guidance to help developers adopt changes confidently. Work with library users across the software stack to understand requirements, resolve integration issues and guide API improvements. The team and culture The AI Compute Libraries team develops high-performance compute libraries and the software infrastructure that helps engineers make effective use of Graphcore’s AI hardware. You’ll work alongside specialists in accelerator software, runtime systems and performance engineering. Together, you’ll turn hardware capabilities and developer requirements into practical, well-tested APIs, with clear documentation and dependable releases. What we’re looking for Essential skills: • Strong modern C++ skills and a commitment to producing reliable, maintainable code. • The ability to turn complex, low-level concepts into clear APIs and abstractions. • Strong debugging and automated testing skills, including diagnosing issues in existing codebases. • Confidence owning substantial engineering tasks independently and working effectively across teams. • Clear written and spoken communication, with a willingness to share knowledge and support colleagues. Desirable experience: • Experience with hardware accelerators, heterogeneous computing or architecture-specific software. • Experience with embedded DSLs, graph representations, descriptor generation or compiler infrastructure. • Familiarity with CMake, C++ library packaging, API/ABI compatibility, versioning or dependency management. • Experience integrating C++ libraries with Python or ML frameworks such as PyTorch. • Experience improving release automation, compatibility testing or developer tooling.
