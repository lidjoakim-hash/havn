Medior Java Developer – AWS & Cloud Operations About the Assignment

KONTORSBEMANNING SVERIGE AB · Göteborg, Sweden

We are looking for a Medior Java Developer with a strong interest in cloud technologies, DevOps and production operations. In this role, you will be part of a collaborative engineering team responsible for developing, maintaining and operating cloud-based backend services within the automotive and connected vehicle industry. You will work across the entire software lifecycle, combining hands-on development with deployment, infrastructure management, monitoring and operational support. The position is particularly suited to someone who enjoys understanding how systems behave in production and continuously finding ways to improve reliability, performance and efficiency. You will have the opportunity to work with modern cloud-native technologies and contribute to services operating in a global environment. Key ResponsibilitiesDesign, develop and maintain backend services using Java and Spring Boot. Build, deploy and operate cloud-native applications within AWS. Work with containerized environments using Docker, Kubernetes and AWS Fargate. Monitor production environments and investigate technical issues. Troubleshoot incidents and contribute to restoring services when disruptions occur. Improve system observability through logging, monitoring, metrics and alerting. Identify opportunities to automate operational processes and repetitive tasks. Support and improve CI/CD pipelines and deployment workflows. Perform root cause analysis and implement long-term solutions to prevent recurring issues. Work closely with developers, architects, QA engineers and other technical stakeholders. Take ownership of technical challenges and ensure problems are followed through to resolution. Required Skills and Experience We are looking for a developer who combines solid software engineering skills with an interest in infrastructure and operational excellence. You should have experience with several of the following technologies and practices:Java development and Spring Boot. AWS cloud services, preferably including AWS Fargate. Kubernetes and container orchestration. Docker and container-based application environments. PostgreSQL and relational databases. DevOps methodologies and CI/CD pipelines. Cloud-native architecture and distributed systems. Monitoring, logging and observability solutions. Troubleshooting and resolving production incidents. Automation and scripting. Git and modern software development workflows. You should also be comfortable participating in an on-call escalation rotation, including occasional support outside normal business hours, once you have gained sufficient knowledge of the systems. About You You are a curious and solution-oriented software engineer who enjoys working at the intersection of development and operations. You take responsibility for the systems you work with and understand the importance of building software that is not only functional but also reliable and maintainable in production. You are proactive when identifying problems, communicate clearly during incidents and enjoy collaborating with colleagues to find effective solutions. We value individuals who:Take ownership and follow tasks through to completion. Have a practical and analytical approach to problem-solving. Enjoy learning new technologies and improving existing solutions. Communicate effectively and work well in a team. Are comfortable working in an environment where development and operations go hand in hand. Continuously look for opportunities to improve processes, performance and system reliability. Core Competencies Technical Skills:Java Spring Boot AWS AWS Fargate Kubernetes Docker PostgreSQL DevOps CI/CD Git Cloud-native technologies Monitoring and observability Language Requirements:English - Fluent / Professional working proficiency Additional Information This is a long-term assignment based in Gothenburg, offering a hybrid working arrangement with approximately 50% remote work.
