Senior Security Engineer Microsoft Security

KUBO International AB · Stockholm, Sweden

💰 ca. 570 000–690 000 SEK/år (estimat · vanlig lønn, ikke bekreftet)Heltidvia ArbetsförmedlingenFrist 20.12.2026

Søk på stillingenÅpne i Havn (lagre, sammenlign, KI-hjelp)

Are you an experienced security engineer who combines technical expertise with a customer-focused approach? We are looking for a Senior Security Engineer to help organisations design, implement and maintain security solutions across the Microsoft ecosystem. You will work across identity, endpoint protection, cloud security and security monitoring, combining advisory responsibilities with hands-on delivery. Apply today and turn security requirements into practical improvements! Key responsibilities Design, implement and maintain security solutions across Microsoft environments, covering identity, endpoints, cloud services and security monitoring. Provide technical expertise across relevant Microsoft Security technologies, including Entra ID, Defender for Endpoint, Defender for Cloud, Sentinel and Intune. Support incident handling, security monitoring and ongoing activities to strengthen customers’ security posture. Assess customer needs and translate technical security requirements into actionable recommendations and business-relevant improvements. Collaborate closely with business stakeholders, IT teams and external providers to deliver and operate security solutions. Act as a technical specialist in customer engagements, combining security advisory with hands-on configuration, implementation and operational support. Ideal candidate profile Senior-level experience designing, implementing or maintaining security solutions in Microsoft environments. Documented expertise in several of the following: Microsoft Entra ID, Defender for Endpoint, Defender for Cloud, Sentinel, Intune, Microsoft 365 Security and Azure. Experience in incident handling, security monitoring or security improvement initiatives. A background in working closely with business stakeholders, IT teams and external providers; consulting or other customer-facing experience would be an advantage. Post-secondary education in IT, cybersecurity or a related field; a relevant university degree and Microsoft certifications in Security, Identity or Azure are advantageous. An independent, accountable approach, strong communication skills and the ability to work both strategically and hands-on; experience with Zero Trust, IAM/PAM, security architecture or organisations in energy, industry or critical infrastructure would be an advantage. Fluency in both Swedish and English. Conditions Location: Stockholm Work Model: Hybrid Employment Type: Full-time employment Recruitment steps Initial call with a KUBO recruiter Interviews with the client Decision and feedback
