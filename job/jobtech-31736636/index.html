About the Role The Data Engineer is responsible for designing, building, and optimizing data pipelines. Build and maintain ETL/ELT workflows and data pipelines to process large datasets efficiently. Design data models, create and maintain views, stored procedures, and other database objects, optimize data storage, and ensure scalability. Implement data governance, access controls, and encryption to protect sensitive information. Key Responsibilities: Analyse business requirements and translate them into technical solutions. Design, develop, and implement ETL/ELT pipelines to migrate data from Tdifferent data sources. Optimize migration processes ensuring data integrity, accuracy, and performance. Create and manage objects (tables, views, schemas, stages, procedures). Implement partitioning, clustering, and performance tuning strategies. Develop and maintain data models, schemas, and stored procedures in databases. Monitor and tune database performance, including warehouse sizing and query optimization and ensure efficient resource utilization and cost optimization. Manage external stages, storage integrations, data security, access controls, and role-based permissions. Automate data ingestion from various sources connectors and external stages using different file format, code pages, and any integration with Saas tools (e.g. dbt cloud, Fivetran, Databricks etc). Rewrite and optimize Teradata SQL scripts, macros, and stored procedures for compatibility. Develop reusable scripts for automation of migration tasks (Python, Shell etc.). Conduct data reconciliation between different database platforms. Work closely with data architects, analysts, and business stakeholders to understand requirements Document migration processes, best practices, and technical solutions.
