An overview of this role As an Intermediate Backend Engineer, Trusted Agentic Development, based in Poland, you'll build backend systems that help GitLab engineers trust the software they create with artificial intelligence agents. Agents can generate code and tests in seconds, but passing tests don't always mean the software works as intended. You'll contribute to validation approaches and feedback mechanisms that help agents catch that gap and self-correct while they work. This isn't a quality assurance or test automation role. We’re looking for someone who has built with agents, run into the gap between passing tests and working software, and wants to help close it. What you’ll do • Own backend features from design through production rollout, making the design calls within the architecture the team agrees on. • Build agentic code-review and validation workflows that check whether generated code does what was intended, not just whether its tests pass. • Prototype focused validation and feedback mechanisms with your teammates, and use what you learn to improve the platform. • Develop language-aware validation approaches, starting with Rust, Ruby, and Go, adapting techniques to each language while applying a shared definition of trusted software to assess whether agent-generated code delivers the intended behavior. • Implement feedback that helps agents identify problems and self-correct during development. • Collaborate with engineering teams to test these approaches in real workflows, measure adoption, engineer trust, and validation quality, and use those measurements to evaluate improvements. • Participate in code and design reviews, explain implementation trade-offs, and seek feedback on your work. • Take part in on-call or operational support where your team's ownership model requires it.
